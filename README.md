# \# 🌈 彩虹歌词 (Rainbow Lyrics)

# 

# 一款针对网易云音乐的 LSPosed / LSPatch 模块，将桌面歌词和状态栏歌词替换为\*\*彩色流光渐变 + 呼吸 + 扭曲 + 粒子消散\*\*效果。

# 

# \## ✨ 功能特性

# 

# \- \*\*流光渐变\*\*：横向流动的彩虹色 Shader，颜色可自定义

# \- \*\*呼吸效果\*\*：透明度正弦波动，幅度可调

# \- \*\*扭曲效果\*\*：热浪 / 水波 / 抖动三种模式，模拟热空气上升

# \- \*\*粒子消散\*\*：歌词切换时上一句化作彩色粒子飘散(未完成)

# \- \*\*桌面歌词接管\*\*：剥离网易云自带的逐字染色，完全由模块控制颜色和动效

# \- \*\*状态栏歌词\*\*：同步支持，独立参数

# \## 📋 要求

# 

# | 项目 | 说明 |

# |------|------|

# | Android 版本 | 8.0+ (API 26+) |

# | 框架 | LSPosed 或 LSPatch(未完成) |

# | 目标应用 | 网易云音乐（com.netease.cloudmusic） |

# | Root | LSPosed 模式需要；LSPatch（未完成） 模式不需要 |

# 

# \## 🚀 安装

# 

# \### LSPosed 模式（推荐）

# 

# 1\. 安装 \[LSPosed](https://github.com/LSPosed/LSPosed)

# 2\. 下载本模块 APK 并安装

# 3\. LSPosed 管理器中勾选模块，作用域勾选\*\*网易云音乐\*\*

# 4\. 打开网易云音乐，进入设置 → 开启「桌面歌词」或「状态栏歌词」

# 5\. 打开模块设置界面，调整参数后点「保存并应用」
